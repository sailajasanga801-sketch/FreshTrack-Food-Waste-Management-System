# FreshTrack - Food Waste Management System

FreshTrack is a web-based Food Waste Management System developed using Python Flask. It helps users manage food inventory, monitor expiry dates, and reduce food wastage.

## Features

- User Registration and Login
- Dashboard with Inventory Statistics
- Add, Edit, Delete and Search Products
- Food Expiry Tracking
- Expiring Soon and Expired Product Alerts
- CSV Upload and Download
- Transaction History
- QR Code Generation
- Barcode Scanning
- POS-Ready Sale Management
- Automatic Stock Updates

## Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Bootstrap
- JavaScript
